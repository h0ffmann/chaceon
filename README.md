# chaceon

WAVEWATCH III® in pure Rust, on the GPU, through [Rust-CUDA](https://github.com/Rust-GPU/rust-cuda)
and [rust-gpu](https://github.com/Rust-GPU/rust-gpu). It is compared with
[metocean/WW3](https://github.com/metocean/WW3) 7.14 (`7.14.mos-92e2cf6`), and it follows the
discipline of [ww3-gpu](https://github.com/h0ffmann/ww3-gpu) without Kokkos.

**State, 2026-10-31:** Rust runs 15 regtests and `ww3_ts1` with `out_grd.ww3`, `out_pnt.ww3` and a last-step
restart byte-identical to the reference, on the CPU at any `--threads N`. With `W3SRCE`, `W3XYP3` and `W3KTP3` as
compiled SPIR-V on CPU Vulkan and `VA` resident on the device, the same files are byte-identical too. **Nothing
has run on a real GPU**, the PTX has never executed, and there are no timings: this is a verification
result, not a speed one. `mod_def.ww3` still comes from the Fortran. MPI is planned and not built.
