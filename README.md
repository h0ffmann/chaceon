WAVEWATCH III® in pure Rust, on the GPU, through [Rust-CUDA](https://github.com/Rust-GPU/rust-cuda)
and [rust-gpu](https://github.com/Rust-GPU/rust-gpu). It is compared with
[metocean/WW3](https://github.com/metocean/WW3) 7.14 (`7.14.mos-92e2cf6`), and it follows the
discipline of [ww3-gpu](https://github.com/h0ffmann/ww3-gpu) without Kokkos.

**State, 2026-11-01:** a run with no Fortran program in it now exists. Rust's `ww3_grid`, `ww3_strt`, `ww3_prep` (for the
cases that have a forcing file) and `ww3_shel`, in sequence from the namelists, give `mod_def.ww3`, `current.ww3`,
`out_grd.ww3`, `out_pnt.ww3` and both restarts byte-identical to the reference on 17 cases, 81 files and
805 162 628 bytes (v, `just rust-only`). `ww3_prep` is ported for the input type `AI` (a field already on the model grid) and
is byte-identical on 14 forcing files of 6 regtests (v, `just prep-all`); the other input types are refused
([report](rust/port_report/WW3_PREP.md)). `ww3_shel` takes
`--threads N` and, built with the feature `mpi`, `mpirun -n R`; both give the same bytes, on 120 MPI runs for R of 1
to 4 (v, `just mpi-pair`). With `W3SRCE`, `W3XYP3` and `W3KTP3` as compiled SPIR-V on CPU Vulkan and `VA` resident on
the device, the same files are byte-identical too. **Nothing has run on a real GPU**, the PTX has never executed, and
there are no timings: this is a verification result, not a speed one.

**What still depends on Fortran.** No Rust binary links Fortran. A run still reads files that Fortran programs wrote where Rust stops: `mod_def.ww3` from `ww3_grid` for unstructured and SMC grids, formatted or unformatted data files (`IDFM` 2 and 3), the old `ww3_grid.inp` and tripole closure; and the forcing file of `ww3_prep` for input types `LL`, `F1`, `F2` and `DAT`, binary input (`IDFM` 3) and a format that reverses. `restart.ww3` can come from Rust's `ww3_strt`, except for start type 2. `ww3_prep` is 1 755 lines, 1% of `model/src`; Rust's covers the input type `AI`, a field already on the model grid. Every verdict also needs the Fortran reference, by design: it is what Rust is compared with.
