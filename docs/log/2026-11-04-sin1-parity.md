## What was read first

`__w3src1md_MOD_w3sin1` in the reference's `ww3_shel` (gdb `disassemble`): `sincosf` once, then
`fmul, fmul, fadd, fmul, fmul, fdiv, fsub, fmaxnm, fmul` per band with `SINC1*SIG2` formed before the final product,
and no fused instruction. The first translation matched without a change.

## Weak and unreached

`ECOS` repeats across the `NTH` blocks (`w3gridmd.F90:1294`), so reading it at the wrong block changes nothing. `FLX1`
of a constant wind gives a constant `USTAR`, so the captures hold four values of it, and a calm run (`USTAR` 2.8e-5)
clamps every band to zero. No NaN input was run ⚠.
