# 2026-11-04: `W3SDS1` at bit parity

`W3SDS1`, the WAM cycle 3 whitecapping of switch `ST1`, translated into `ww3-kernels` with SPIR-V and PTX entry
points. Status `routine` (`rust/port_report/W3SDS1.md`). Nothing ran on a GPU. No timings. Not called from `W3SRCE`.

The `calm` capture has `EMEAN = 0` on every call, so its `S` and `D` are all zero: it counts for nothing.

## Reading the compiled code first

The routine is three lines of arithmetic, and the one place a bit can go is the association of
`FACTOR = SDSC1 * FMEAN * WNMEAN**3 * EMEAN**2`. The disassembly of `__w3src1md_MOD_w3sds1` in the reference's
`ww3_shel` (gdb, `chaceon-ref-capture:switch_chaceon_st1`) shows `((SDSC1*FMEAN) * ((W*W)*W)) * (E*E)`, left to right
with both powers as product chains, then `D = FACTOR*K` and `S = D*A` as two vectorised element-wise loops. Nothing
fuses. That is the order the kernel has; the first capture matched on the first try.

## Faults

Six faults on `default, 8 m`, all caught in both layouts (`SDS1_FAULT` in `sds1_cmp`): `SDSC1` one ULP up, `FACTOR`
reassociated, `FACTOR` in `f64`, `WNMEAN**2` for `**3`, `K` of the next bin, `S = FACTOR*(K*A)`. The last leaves `D`
equal, so `S` and `D` fault separately. The routine has no guard, so no input needed poking.

## Notes for whoever wires `ST1` into `W3SRCE`

- `W3SRCE` calls it as `CALL W3SDS1 ( SPEC, WN2, EMEAN, FMEAN, WNMEAN, VSDS, VDDS )` (`w3srcemd.F90:1288`); `K` is
  `WN2`, one wavenumber per spectral bin, so the kernel takes it with its own offset.
- `SDSC1` is `TPI * CDIS / APM**2` and reaches the routine through `MPARS`; the capture reads it from
  `w3gdatmd::sdsc1`. `mod_def.ww3` carries it (`w3iogrmd.F90:1182`).

## Environment notes

- `docker/Dockerfile.ptx` is matched by the `*.ptx` line of `.gitignore`, so a fresh clone or worktree does not
  have it and `just ptx` stops at `docker build`. It was copied in from the main checkout for this run.
- A worktree's `WW3/` submodule is empty; the capture scripts mount `$PWD/WW3`. Pointing it at the main checkout's
  `WW3/` for the run was enough.
- The machine was short of disk space for a few minutes during `just spirv` with ten agents building, and rustc
  failed with ENOSPC; a rerun passed.
